Mi Despensa

Aplicación propia para gestionar la despensa de casa.

Objetivos

* Controlar el inventario de productos.
* Registrar compras y consumos.
* Crear una lista de la compra automática.
* Consultar el historial de movimientos.
* Guardar los datos localmente para trabajar sin conexión.
* Incorporar lectura de códigos de barras en una futura versión.

Desarrollo

Proyecto personal desarrollado desde una tablet Android, con código propio y ampliaciones futuras.

Estado

Preparación inicial del proyecto.
